# UWB 3대1 삼변측량 결과 (2026-11-23)

실기체 실험 진행계획 **단계 2-1·2-3**과 삼변측량 방법론 **3-1**에 따라, 앵커 3대와 1호기 태그로 위치를 계산하고 줄자 위치와 비교했습니다.

## 한 줄 요약

**바닥 높이(9 cm)에서 가려지지 않은 지점의 수평 위치 오차는 4.5~7.9 cm입니다.** 같은 자리를 다시 재면 1 cm 안에서 같게 나오고, 측정 성공률은 대부분 97% 이상입니다. 오차가 커진 경우는 두 가지였습니다. 한 지점에서 A3 신호가 가렸을 때(13.3 cm)와 태그를 82 cm 높이로 올렸을 때(29~36 cm)입니다.

## 4. 해석

1. **바닥 높이 위치 정확도는 4.5~7.9 cm입니다** (P1, P3, P4, P5). 같은 자리를 다시 재면 계산 위치가 1 cm 안에서 같게 나옵니다(P4 1차·2차, 0.6 cm 차이). 측정은 안정적이고, 남은 오차는 고정된 원인에서 옵니다.
2. **A1·A2 거리는 바닥 높이 지점에서 모두 ±5 cm 이내입니다.**
3. **A3는 가까울 때 짧게, 멀 때 길게 나옵니다.** P4 −10 cm, P1 −6 cm, P5 +7 cm 순입니다. 일정한 값을 빼는 보정(안테나 지연)만으로는 맞지 않습니다. A3 좌표나 드론을 놓은 위치의 cm 단위 차이가 섞였을 가능성이 있습니다. A3 바닥 위치를 아직 실측하지 않았습니다.
4. **P2의 A3는 가림 징후가 뚜렷합니다**(첫 경로가 13.9 dB 약함). 거리가 −21 cm 틀어졌고 위치 오차가 13.3 cm로 커졌습니다. 그때 드론 몸체·덕트 방향이나 주변 물체가 A3 쪽을 가렸을 수 있습니다.
5. **A3 성공률은 일부 지점(P3, P4)에서 약 89%, 높이 82 cm(P6)에서 약 79%로** 다른 앵커(97~100%)보다 낮습니다.
6. **82 cm 높이(P6)에서는 A1 거리가 28~35 cm 길게** 나왔습니다. 두 번 쟀을 때 A2·A3는 거의 같았는데 A1만 7 cm 달라졌고 흔들림도 커졌습니다(4~6 cm). 드론 위치보다는 **A1 쪽 반사 경로**가 섞였을 가능성이 큽니다. 받침대 재질과 주변 물체, 드론 실제 x, y 확인이 필요합니다.
7. **11/22 1대1에서 보였던 +0.55 m 고정 오차는 이번에 나타나지 않았습니다.** 이번 앵커 펌웨어에는 송신 전력 변환이 들어가 있습니다.

## 5. 측정 중 있었던 일

- **불량 의심 EVB 1개:** 1호기 NUCLEO에 처음 꽂은 DWM3000EVB는 칩이 응답하지 않았습니다(`SYS_STATUS 0xFFFFFFFF`, `TWR3_INIT_FAILED`). 11/22에 정상 동작한 1대1 펌웨어로도 같았고, 다른 EVB로 바꾸자 바로 `TWR3_READY`가 나왔습니다. **그 EVB에 불량 의심 표시를 붙여 주세요.**
- **앵커 ID 뒤바뀜:** 2절 참고.
- **앵커 2대만 켜졌을 때:** 앵커당 측정 횟수가 약 12~14회/s로 줄었습니다. 3칸 중 2칸만 쓰이기 때문입니다.
- 태그 기록은 22:28:13에 USB를 뽑으면서 끝났습니다.

## 6. 남은 일

1. **A3 바닥 위치 실측:** A1 바닥 → A3 바닥, A2 바닥 → A3 바닥 거리를 잽니다. 기록대로면 둘 다 503 cm입니다.
2. **드론 위치를 원점에서 줄자로 직접 재기:** 이번에는 "90 cm 이동"으로 위치를 정했습니다. 절대 좌표로 재면 위치를 놓은 오차가 빠집니다.
3. **안테나 지연 보정 (계획서 2-2):** 1·2번 뒤에 남는 앵커별 공통 오차로 정합니다.
4. **P2 가림 원인과 P6 높이 82 cm 원인 확인:** 드론 방향을 돌려서, 또는 받침대를 바꿔서 다시 잽니다.
5. 삼각형 밖 지점(외삽), 사람 가림 조건, 지점당 1,000회 × 3회 반복(계획서 측정 0, C1).

## 연동성 (미확인 위주)

| 연결 | 판정 | 해야 할 일 |
| --- | --- | --- |
| XIAO ↔ PC 동글 (BLE) | 실측 완료 | 드론 ↔ 드론은 별모양 구조라 2홉 중계 또는 광고 방식 결정 |
| MTF-01 → FC | 가능 (UART MAVLink) | `FLOW_ORIENT_YAW`, `mav_id`, `RNGFND1_ORIENT=25` 확인 |
| N6 ↔ FC | 가능 (추정) | STM32N6 + MAVLink 선례 없음. heartbeat부터 시험 |
| DWM3000EVB → N6 Zio 헤더 | 미확인 | SPI로 DEV_ID 읽기, 3.3 V 로직 확인 |
| Qorvo API → STM32N6 | 포팅 필요 가능성 큼 | SPI / IRQ / 타이머 어댑터 작성 |
| EVB(태그) ↔ DWM3001CDK(앵커) 측거 | 공식 예제 없음 | 채널, 프리앰블, 데이터율, STS 설정 일치 후 DS-TWR 직접 빌드 |
| ToF ×5 → TCA9548A → N6 | 가능 (추정) | 5개 동시 연속 측정 시험 |
| N6 ↔ XIAO | 미확인 | UART(921600) 가정으로 시험 |
| Zio 헤더 핀 총량 | 미확인 | SPI(UWB) · I2C(ToF) · UART ×2 · CSI · SD · LED 핀 배정표 작성 |
| 탑재 | 문제 가능성 큼 | NUCLEO, EVB, 카메라가 3인치급 기체(프롭 76 mm)에 무거움. 지상 보드로 먼저 시험 |

### Task 4: XIAO nRF52840 ↔ 동글 (2026-11-09)

| 측정 | 결과 |
| --- | --- |
| 처리량 | 20 ~ 240 B, 연결 간격 7.5 ~ 100 ms 전 조건 3.2 kB/s 이상. 최고 약 109.5 kB/s (240 B, 15 ms) |
| 요구치 50 Hz × 64 B | 간격 7.5 / 30 / 100 ms 모두 손실 0 (9회, 27,013 패킷) |
| RTT (1,000회) | 7.5 ms 간격 평균 26 ms, 30 ms 간격 55 ms, 100 ms 간격 180 ms. 응답률 100% |
| 거리별 (50 Hz × 64 B, 각 60 s, 실내 복도) | 1 / 5 / 10 m 손실 없음 (RSSI -58 / -72 / -76 dBm). 20 m 4회 중 3회 정상, 1회 수신 28.9% 부족 (원인 미확인) |

해석: 왕복 지연은 연결 간격이 정한다. 이벤트 트리거로 전송 횟수를 줄여도 연결 간격은 짧게 유지한다.

## 막힌 곳과 해결

`hw-bench/삽질기록.md` 에 있다. 대표 사례:
- 동글에 central 펌웨어를 올리면 USB 미인식 → `CONFIG_BT_SETTINGS=n`
- 최대 속도 송신에서 손실 22 ~ 75% → MTU 247, ACL 버퍼 251, 힙 16384 B로 확대
- 연결 콜백에서 PHY, MTU, 연결 간격을 동시에 요청하면 알림 구독 실패 → 측정 전에 명령으로만 요청

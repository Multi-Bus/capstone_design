# 참고 사례와 출처

발표에서 "다른 사람들은 이렇게 했다"를 말할 때 쓰는 사례 모음이다. **확인 수준을 반드시 같이 적는다.** 조사 시점의 열람 수준이며, 발표에서 수치를 직접 인용하려면 원문 본문을 다시 확인해야 한다.

미팅 보고 A와의 대응: 1절은 환경 근거, 4 ~ 6절은 알고리즘 구체화(CBF-QP, 편대, 이벤트 트리거), 2 · 3 · 7절은 그 알고리즘에 입력을 주는 부품의 근거다. 성과 지표(E1 ~ E6)는 [결과 산출 계획](05_결과_산출_계획.md) 3절을 따른다.

확인 수준: **본문** = 본문에서 직접 확인 / **초록** = 초록 · 검색 요약 수준 / **스니펫** = 검색 결과 조각 / **원문 미확인** = 서지만 기억 또는 인용

## 8. 사례가 없는 것

발표에서 "선행 사례가 없다"고 말할 수 있는 항목이다. 근거는 조사 시점(2026-10)의 검색이며 "존재하지 않음"의 증명은 아니다.

- 통신 지연 실험에서의 안전 여유 정량화 (8차 회의 표).
- 메모리 · 전력 지표를 포함한 경량화 평가 (차별 지표 후보).
- DW3000으로 군집 정확도를 낸 논문.
- 고정 RGB 카메라 + 가시광 LED 마커로 여러 드론을 구분한 논문.
- STM32N6 + MAVLink 구성.

## 9. 인용 전 점검표

- [ ] 발표에 쓸 수치는 원문 본문으로 재확인했는가.
- [ ] 시뮬 결과를 "실기체 성능"처럼 말하지 않았는가.
- [ ] 저자명 · 연도가 기억 기반인 항목을 원문으로 바로잡았는가.
- [ ] 우리 실측(Task 1 ~ 4)과 문헌 수치를 구분해 말하는가.

## 위험

| 위험 | 대응 |
| --- | --- |
| UWB 시험이 통과 기준(거리 0.10 m, 위치 0.15 m)을 못 넘음 | 고정 ZED 2i로 전환 (8 m × 8 m 한계) |
| 사람 · 벽 가림(NLOS)이 위치 오차 +29 ~ 36 cm 유발 | 진단값으로 이상치 제거, 앵커 4개 검토 |
| 탑재 중량 (NUCLEO, EVB, 카메라) | 지상 보드로 먼저 연동 시험, 소형 보드 대안 |
| D_eff 0.85 m 이상으로 6대에게 과대 → 교착 | `v_max` 하향, 오차 상한 정밀화 |
| BLE 20 m 구간에서 1회 28.9% 수신 부족 | 원인 조사, 실제 운용 거리 재측정 |
| 기존 설계가 Wi-Fi · chrony · Raspberry Pi 전제 | BLE · MCU 기준으로 통신 설계 재작성 |
| 종강까지 약 4주, 남은 일이 많음 | 3단계(1대 비행)까지 실측하고 나머지는 시뮬로 채움 (팀 합의 필요) |

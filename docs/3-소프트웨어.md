# 3. 소프트웨어

구현된 것: `hw-bench`의 BLE 링크 펌웨어(XIAO, 동글)와 측정 스크립트뿐이다. 아래 모듈은 설계 단계이며 N6 위에서 돌린다.

## 데이터 흐름

```
[1 내 상태]  UWB 거리 3개 → 수평거리 환산 → 이상치 제거 → 3점 위치 → 월드→NED → ODOMETRY(MAVLink2) → FC
             FC EKF(UWB 위치 + 광류 속도 + IMU) → 융합된 p, v, 자세를 N6로 회신
[2 이웃]     BLE 패킷(id, t_tx, p, v, seq) → 순번 검사 → 시계 보정 → 외삽 → AoI · stale 판정
[3 장애물]   ToF ×5 → 필터 → 몸체→월드 변환 → 이웃과 중복 제거 → 장애물 점
[4 편대]     v_nom = v_ref + Σ k_c ((p_j - p_i) - (오프셋_j - 오프셋_i))
[5 CBF-QP]   이웃별 D_eff, 장애물별 D_obs, |v| ≤ v_max 제약 → v_safe  (해 없으면 감속 · 정지)
[6 명령]     v_safe(NED) → SET_POSITION_TARGET_LOCAL_NED, 20 ~ 50 Hz (끊기면 3 s 뒤 정지)
[7 기록]     SD + 동글 텔레메트리 → E1 ~ E6 지표
```

## 모듈 책임

| 모듈 | 입력 | 출력 |
| --- | --- | --- |
| 위치 추정 | UWB 거리, MTF-01 고도 | ODOMETRY (공분산 포함) |
| 이웃 상태 | BLE 패킷 | 이웃별 `p̂_j`, `v̂_j`, AoI, stale |
| 장애물 | ToF 거리 | 장애물 점 |
| 편대 제어 | `p_i`, `p̂_j`, 역할 ID | `v_nom` |
| 안전 필터(CBF-QP) | `v_nom`, 이웃, 장애물 | `v_safe` |
| FC 인터페이스 | `v_safe` | MAVLink 속도 명령 |
| 기록 | 전 모듈 | SD 로그 (송수신 타임스탬프 포함) |

인터페이스는 `v_nom → v_safe` 함수 하나로 편대 제어와 안전 필터를 분리한다.

## 규칙과 설정값

| 항목 | 값 | 비고 |
| --- | --- | --- |
| 우선순위 | 안전 > 편대 유지 > 목표 도달 | |
| 위치 필터 | 이동평균 사용 안 함 | 3점 평균은 20 Hz에서 50 ms 지연. 평활은 FC EKF에 맡김 |
| 이웃 패킷 | 64 B × 50 Hz (BLE 실측 요구치) | 기존 31 B × 20 Hz 설계는 팀 합의로 통일 필요 |
| 방송 기준선 | 20 Hz 주기 방송, 10 Hz 추가 조건 | 이벤트 트리거와 비교 |
| N6 ↔ FC UART | 460800 baud 이상 | 115200은 부족 (약 139 kbaud 필요) |
| 이상 상황 | stale → D_eff 확대, 링크 단절 → 마지막 위치 + 확대 반경, QP infeasible → 감속 | |
| UWB 접근 | 시간 분할(TDMA) 필수 | 동글 비콘으로 슬롯 동기 방안 |

## 지연 예산 (계산 · 추정 · 가정, 실측 아님)

| 체인 | 지연 | 비고 |
| --- | --- | --- |
| 내 위치 (UWB → FC) | 약 6 ~ 15 ms | 최악 80 ms. 갱신 주기 대기 별도 |
| 이웃 상태 (BLE 2홉) | 약 60 ~ 80 ms (간격 7.5 ms) ~ 220 ms 이상 (간격 100 ms) | RTT 실측에서 계산 |
| 장애물 (ToF → FC) | 약 13 ~ 50 ms | 감지 거리 1.3 m (short)로 여유 적음 |
| 카메라 | 약 60 ~ 110 ms | 전부 가정. 후순위 |
| 속도 추종 τ | 0.2 ~ 1.0 s | 가정. **가장 큰 값, 실측 필요** |

## 시계 동기

기존 설계는 chrony(NTP)를 전제했으나 N6는 Linux가 없는 MCU라 쓸 수 없다. BLE 기반 시계 동기를 새로 설계해야 한다. 미결정.

## 환경 설치

- Arduino IDE + Seeed nRF52 Boards (XIAO), nRF Connect SDK (동글), STM32CubeIDE (N6)

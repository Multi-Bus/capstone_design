# CLAUDE.md (묶음 최상위)

이 폴더는 N6 드론 프로젝트 인수인계 묶음입니다. **사용자에게는 한국어로 답하세요.**

- 주 프로젝트는 `stm32_projects/`입니다. 작업 전에 **`stm32_projects/CLAUDE.md`**(안전 규칙, 함정, Windows 주의점)와 **`stm32_projects/HANDOFF_KO.md`**(진행 상황, 남은 문제는 6장)를 먼저 읽으세요.
- 안전 규칙 요약: 보드 플래시 쓰기, 모터가 돌 수 있는 명령(시동·이륙·모터 시험), FC 파라미터 쓰기는 **반드시 사용자에게 먼저 묻고** 실행하세요. 프롭을 단 상태에서는 시동·이륙 명령을 직접 보내지 않습니다.
- `fc_control/n6_fc_setup/`은 FC 파라미터 파일과 Linux 전용 설정 스크립트입니다. `n6_params/`는 FC 원래 값 백업입니다.

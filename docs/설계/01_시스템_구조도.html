드론 내부 데이터 흐름도

부품 사이를 오가는 데이터가 어떤 형태이고, 어디서 어떻게 전처리되어 다음 부품으로 가는지 한 장에 모았다. 부품을 누르면 오른쪽에 받는 것 · 보내는 것이 나오고, 화살표나 표의 행을 누르면 아래에 전처리 단계가 나온다. 영역 버튼으로 걸러 볼 수 있다.

① 부품 · 연결 · 데이터 흐름

화살표 위 굵은 글씨는 보내는 데이터, 그 아래는 전처리다. 점선 테두리는 기체 밖이다. 회색 배경은 컴패니언(N6)이다.

데이터 방향선 색 = 영역상태 표기: 실측 / 확인 / 추정 / 미확인

② N6 내부 소프트웨어 계층: 값의 조합과 연산

N6 안에서 값이 다음 단계로 넘어갈 때 어떤 값들을 조합해 무슨 연산을 하는지다. 이해가 목적이라 기호 대신 말로 적었다. 연산 시간은 모두 미측정이다. 편대 제어와 안전 필터의 인터페이스는 "원하는 속도 → 안전 속도" 함수 하나라 회피 알고리즘(CBF / ORCA / APF)을 바꿔 끼울 수 있다.

① 입력 만들기IN
  • 이웃 예측 위치 = 이웃이 보낸 위치 + 이웃 속도 × (지금 시각 − 이웃이 보낸 시각) 패킷이 오는 동안 이웃이 움직인 만큼을 더한다 (외삽). 시계 오프셋 보정 포함
  • 정보 나이 = 지금 시각 − 마지막으로 받은 시각 기준을 넘으면 낡은 정보(stale)
  • 장애물 위치 = 내 위치 + 자세로 돌린 (센서 방향 × ToF 거리 + 센서 장착 위치) status가 정상이 아니면 버림, 이웃 근처면 이웃으로 연결
  • 내 위치 · 속도 · 자세 UWB 위치 + 광류 속도 + IMU를 FC가 융합해 회신 (N6는 연산 안 함)
↓
② 편대 제어 (Consensus)원하는 속도

원하는 속도 = 편대 이동 속도 + 이웃마다 [ 맞추는 강도 × (실제 상대 위치 − 대형이 요구하는 상대 위치) ]의 합

조합 값: 편대 이동 속도, 내 위치, 이웃 예측 위치, 역할 번호로 정한 대형 위치, 맞추는 강도. 대형이 이미 맞으면 보정이 0이라 편대 이동 속도만 남는다. 목표점으로 가는 편대 이동 속도 산출식은 [제안]이며 확정 전이다.

원하는 속도 ↓
③ 제약 만들기 → ④ 안전 속도 고르기안전 속도
  • 이웃 안전거리 = 기본 거리 + 내 위치 오차 + 이웃 위치 오차 + 상대속도 상한 × 정보 나이 + 시계 오차 정보가 낡을수록 거리를 넓힌다
  • 이웃 접근 조건 여유 = (이웃과의 거리)² − 안전거리². 이웃에서 나를 향한 방향으로의 내 속도가 (이웃의 같은 방향 속도 − ½ × 감쇠 계수 × 여유)보다 작아지지 않게 한다 여유가 작을수록 접근을 더 강하게 막는다
  • 장애물 접근 조건 이웃과 같은 방식. 장애물은 정지해 있어 장애물 속도가 0
  • 속도 상한 속도 크기가 최대 속도를 넘지 않게 한다
  • 안전 속도 고르기 (QP) 제약을 모두 지키는 속도 중 원하는 속도에 가장 가까운 것. 제약 수 = 이웃 수 + 장애물 점 수 + 1
  • 해가 없으면 감속하거나 멈춘다. 교착 지표로 센다
안전 속도 ↓
⑤ 명령 출력 · ⑥ 송신 판단OUT
  • 명령 안전 속도(방 좌표)를 FC 좌표(NED)로 바꿔 [제안] (북쪽 = 방 y축, 동쪽 = 방 x축, 아래 = −높이) MAVLink 속도 명령으로 보낸다. 20 ~ 50 Hz
  • 송신 판단 예상 위치 = 마지막에 보낸 위치 + 마지막에 보낸 속도 × 경과 시간. 실제 위치와 예상 위치의 차이가 임계값을 넘으면 내 상태 64 B를 방송한다 임계값은 이웃 쪽 안전거리에 "이웃 위치 오차"로 더해진다
예시

계산 예시 (설명용 가정값)

한 이웃이 내 쪽으로 다가오는 상황. 내 위치 (0, 0), 이웃 예측 위치 (1.2, 0), 이웃 속도 (−0.5, 0), 원하는 속도 (1.0, 0), 안전거리 0.85 m, 감쇠 계수 1. 측정값이 아니다.

여유 = 1.2² − 0.85² = 1.44 − 0.7225 = 0.7175
이웃에서 나를 향한 방향 = (−1.2, 0)
허용 기준 = (−1.2)(−0.5) − ½ × 1 × 0.7175 = 0.2413
조건: (−1.2) × (내 x속도) ≥ 0.2413  →  내 x속도 ≤ −0.201
원하는 속도 (1.0, 0)은 조건을 어긴다
조건을 지키는 속도 중 가장 가까운 것  →  안전 속도 = (−0.201, 0)

안전거리 여유(1.2 − 0.85 = 0.35 m)가 작고 서로 접근하면 전진 명령이 후퇴 명령으로 바뀐다. 이웃이 멀거나 멀어지면 조건이 느슨해서 원하는 속도가 그대로 통과한다.

속도 명령이 즉시 실현된다고 가정한다. 실제로는 속도 추종 지연만큼 늦어 안전거리와 최대 속도로 보상한다(지연 미측정). N6용 QP 솔버 선정과 1주기 시간은 미측정이다. 식은 평면(2D)으로 적었고 3D 확장은 미정이다.

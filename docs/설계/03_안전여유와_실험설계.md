# 안전 여유와 실험 설계

## 안전 여유 (D_eff)

CBF는 이웃의 실제 위치를 안다고 가정한다. 실제로는 오차와 지연이 있어 안전거리에 상한을 더한다.

```
D_eff,j = D_base + ε_self + ε_nbr,j + v_rel,max × (이웃 정보 나이) + ε_sync
```

이벤트 트리거를 쓰면 `ε_nbr,j = δ(트리거 임계값) + ε_sync`가 되고, 정보가 낡으면 `v_max × AoI`로 교체한다.

| 항 | 값(가정) | 근거 |
| --- | --- | --- |
| D_base | 0.40 m | 시뮬 가정 (반경 0.2 m 두 대). 8차 회의록은 충돌을 0.3 m 미만으로 정의해서 두 값 정합이 필요 |
| ε_self | 0.15 m | UWB 위치 RMSE 통과 기준 |
| ε_nbr | 0.15 m | 이웃도 같은 UWB. 오차 상쇄는 검증 전이라 가정하지 않음 |
| 지연 항 | 0.14 m (BLE 연결 간격 7.5 ms) ~ 0.44 m (100 ms) | 상대속도 2 m/s × 2홉 정보 나이 (외삽 효과 미반영, 보수적) |
| ε_sync | 0.01 m | 2 m/s × 5 ms |
| 합계 | 약 0.85 m ~ 1.15 m | 6대에게는 큰 값이라 교착 위험 동반 |

읽는 법:

- 연결 간격이 짧으면 위치 오차 두 항이 지배하고, 길면 지연 항이 지배한다.
- 위치 통과 기준(0.15 m)을 낮추면 D_eff가 직접 줄어든다.
- 속도 추종 지연 τ(시뮬 가정 0.2 ~ 1.0 s)는 위치 오차가 아니라 모델 오차다. 실기체 측정 전에는 margin을 확정할 수 없고, 대응은 `v_max` 하향이다.
- 시뮬에서 ORCA는 τ ≥ 0.5 s에서 안전거리를 침범했고, 여유(0.1 m)를 둔 CBF는 τ = 1.0 s에서도 한계 근처(최소 이격 0.406 m)에서 버텼다. 알고리즘보다 "안전거리에 얼마의 여유를 두는가"가 안전을 좌우한다. (파이썬 시뮬 값이며 실기체 성능이 아니다.)

## 교착 위험

여유를 크게 잡을수록 안전하지만, 서로 길을 막아 멈추는 위험이 커진다. 제약을 만족하는 속도가 없는 경우가 원인이다.

- 탐지 [제안]: 목표에서 먼데 속도 ≈ 0인 상태가 일정 시간 지속되면 교착으로 판정한다.
- 완화: 우선순위(한 대 먼저 통과), 작은 랜덤 교란, 목표 재배정, 목표점을 서로 충분히 떨어뜨려 뽑기.

## 실험 설계 (E1 ~ E6)

한 번에 한 요인만 바꾼다. 같은 지표를 모든 실험에서 기록한다.

| 실험 | 바꾸는 요인 | 비교 대상 | 본 문서 외 참고 |
| --- | --- | --- | --- |
| E1 | 통신 방식 | 20 Hz 주기 방송(기준선) / 이벤트 트리거 / 중앙 우선순위 | BLE 실측: [실측 결과](../하드웨어/06_실측_결과.md) |
| E2 | 이벤트 임계값 δ | δ를 바꿔 통신량 대비 안전 손실 측정 | δ는 D_eff에 더해진다 |
| E3 | 통신 지연 | BLE 연결 간격, 인위 지연 | 선행 사례 없음(8차 회의 표) |
| E4 | 센서 구성 | ToF 유무 · 개수 | ToF 미측정 |
| E5 | 규모(기체 수) | 6대 실기체 + 시뮬 6 → 20 → 50 → 100 | 이웃 선별은 시뮬 확장성 |
| E6 | 회피 방식 | CBF / APF / ORCA / MPC 계열 | 시뮬 비교 수치 있음 |

### 기록 지표

| 분류 | 지표 |
| --- | --- |
| 안전 | 충돌 횟수 · 성공률, 안전 위반 비율, 최소 이격 거리 |
| 정확도 | 편대 오차(RMS), 복귀 시간, 도달 시간, 교착 비율 |
| 경량화 | 통신량(메시지 수 · 바이트), 1주기 계산 시간(평균 · p99), 메모리, 전력 |

평균만 보면 괜찮아도 p99가 10배 튈 수 있다. 제어 주기 안에 못 끝나는 순간이 사고가 되므로 평균과 p99를 둘 다 기록한다.

### 단계

시뮬 → 벤치 → 1대 → 2대 → 6대 순서로 진행한다. 다음 단계로 넘어가는 조건은 [결과 산출 계획](../스토리텔링/05_결과_산출_계획.md)에 둔다.

## 환경 근거 요약

물류센터는 재고 조사와 운송이 반복되는 실내 공간이다. 선행 연구(Apostolidis 외, 2022) 시뮬레이션에서 넓은 영역의 소요 시간이 1대 257.05분에서 9대 54.28분으로 줄었다. 기체가 늘면 간섭도 늘어 편대 제어와 회피가 필요하다. 비행 시간이 길고 기체당 작업량이 클수록 필요한 기체 수가 줄어 경량화가 필요하다. 상세는 [환경 구성 근거](../스토리텔링/02_환경_구성_근거.md)에 있다. 개선 방향 선택지 지도: [개선선택지_지도.html](../files/개선선택지_지도.html).

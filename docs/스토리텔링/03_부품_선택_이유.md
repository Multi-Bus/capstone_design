# 부품 선택 이유

센서와 부품마다 "무엇을 후보로 놓고, 무엇을 골랐고, 왜 그랬는가"를 모은다. 슬라이드 6의 근거다. 근거 수준은 2026-10-17 부품 조사(논문 · 판매처 열람)와 벤치 실측이다. 조사에서 못 찾은 것은 "선례 없음"으로 적고, 시험으로 정한다.

## 1. UWB (위치 · 좌표계)

| 후보 | 특징 | 판단 |
| --- | --- | --- |
| **Qorvo DWM3000EVB(태그) + DWM3001CDK(앵커)** | DW3000 계열. 단가 낮음(CDK 약 38,850원 추정, 구매 137,184원 / 3개). 태그 · 앵커 같은 계열 | **채택** |
| MaUWB ESP32-S3 (Makerfabs) | DW3000 + ESP32-S3, 115,500원. 정적 DRMS 1.2 cm, 사람 걷기 17.25 cm (스니펫) | 단가 부담, 대안 |
| Nooploop LinkTrack | ArduPilot 네이티브 지원(`BCN_TYPE=3`). 공식 문서는 앵커 4 + 태그 1 | 3앵커 시험에 안 맞아 보류 |
| Bitcraze Loco Positioning | 문헌 가장 풍부(군집 TDoA 10 ~ 20 cm). DW1000 구세대, Crazyflie 전용 | 제외 |
| Pozyx | 서비스 종료 | 제외 |

- 논문 기준 군집 UWB 정확도는 10 ~ 30 cm 수준이고, 우리 목표(거리 0.10 m)는 문헌보다 빡빡하다. 교수 의견도 "UWB는 기대보다 나쁠 수 있다"였다. 그래서 **통과 기준과 대안(ZED 2i)을 함께** 둔다.
- 실측: LOS 오차 2 cm 안팎, 가림 +29 ~ 36 cm. 부품 선택은 맞았고 문제는 환경(가림)이다.
- 위험: EVB ↔ CDK 상호운용에 공식 예제가 없고 N6 API 포팅이 필요하다.

## 2. 근거리 ToF (장애물)

| 후보 | 특징 | 판단 |
| --- | --- | --- |
| **VL53L1X ×5 (Pololu 3415)** | 단일 빔 27°, 4 m(암실) / 1.3 m(short), 50 Hz, I2C, 0.5 g | **채택** |
| VL53L5CX 멀티존 | 8×8, 대각 65°, 0.5 g. 전방 1면만 교체하면 6대 기준 약 +46,000원 | 전방 옵션 |
| TF-Luna | FoV 2°로 좁아 정조준 필요 | 제외 |
| TFmini Plus | 12 g, 약 550 mW | 제외 |

- 선례: Bitcraze Multi-ranger 덱이 단일 빔 ToF 5방향 구성(Crazyflie)이다. Müller 외(2022)는 멀티존 ToF로 실내 0.5 m/s에서 신뢰도 100%를 보고했다.
- 한계: 얇은 막대(Ø 40 mm) 검출 근거는 없다. 1.2 m에서 빔 폭 약 0.58 m라 막대는 약 7%만 채운다. 어두운 표면에서 짧게 잡힌다. 마주 보는 센서 간 간섭 보고가 있다.
- 구조: 같은 주소(0x29) 5개를 TCA9548A로 분리한다.

## 3. 광류 + 하향 거리

| 후보 | 특징 | 판단 |
| --- | --- | --- |
| **MicoAir MTF-01** | 광류 42° + ToF 일체, 4.5 g, UART MAVLink, 연구실 보유 | **채택** |
| Holybro PMW3901 | 광류만, 거리 센서 별도 | 제외 |
| Holybro H-Flow | 15.2 g, DroneCAN | 제외 |

- 실내 정량 정확도 자료는 못 찾았다. 포럼에는 실내 고도 진동 사례(±0.6 m)가 있어 직접 시험이 필요하다. 이 고도가 UWB 수평거리 환산에 쓰이므로 중요하다.

## 4. 컴패니언

| 후보 | 특징 | 판단 |
| --- | --- | --- |
| **NUCLEO-N657X0-Q (STM32N6)** | MCU로 실시간성, 카메라 CSI 입력, NPU. 팀 구매 시트 확정 | **채택** |
| Raspberry Pi 4 / 5 | Linux, ROS 2, chrony 사용 가능. 큰 무게 · 전력 | 초기 가정, 폐기 |
| Teensy | 초기 MCU 후보 | 폐기 |

- 장점: Pi 대비 결정적 실행. 실측: 행렬곱 4.7 µs, PID 0.23 µs, 인터럽트 jitter 0.18 µs.
- 대가: Linux가 없어 ROS 2 · chrony를 쓰지 못한다. STM32N6 + MAVLink 선례가 없다. NUCLEO + EVB + 카메라가 3인치 기체에 무겁다.

## 5. 드론 간 무선

| 후보 | 특징 | 판단 |
| --- | --- | --- |
| **BLE (XIAO nRF52840 ↔ 동글)** | 요구치 64 B × 50 Hz 손실 0 실측 | **채택** |
| Wi-Fi UDP 방송 | 초기 1차 후보. Pi 가정에서 추가 하드웨어 없음 | 폐기. N6에는 내장 Wi-Fi가 없음(일반 지식) |
| ESP-NOW | 기본 1 Mbps, 제3자 측정 5 ~ 11 ms @ 10 m. 추가 보드 필요 | 대조군이었으나 BLE로 진행 |
| SiK 915 MHz | 기본 64 kbps. 50 Hz 페이로드 74.4 kbps를 담지 못함(계산) | 제외 |

- 구조 문제: BLE는 별모양이라 드론 ↔ 드론이 2홉이다.
- 실측에서 연결 간격이 RTT를 정했다(26 ms ↔ 180 ms).

## 6. 카메라와 마커

| 부품 | 이유 |
| --- | --- |
| STEVAL-66GYMAI1 (VD66GY, 글로벌 셔터) | 롤링 셔터 왜곡이 없어 점멸 LED 촬영에 유리. N6 CSI와 연결 사례가 있음 |
| WS2812B + 디퓨저 | 가시광 LED로 식별. 논문 선례는 IR/UV + 이벤트 카메라가 많고, 가시광 + 일반 카메라는 직접 근거를 못 찾음 |

- 위치: 후순위. 제어 입력에 아직 쓰지 않는다.
- 이유(지도교수): 센서를 과하게 달면 무게 · 연산 · 배터리 부담이 커진다.

## 7. 대안 위치 소스: ZED 2i

연구실 보유 3대. 고정 설치해 마커를 추적한다. 8 m × 8 m가 한계다. 선례(ZED로 여러 드론을 cm 단위로 추적한 논문)는 못 찾았다. UWB가 통과 기준을 못 넘을 때만 쓴다.

## 8. 선택의 공통 원칙

1. **가볍게**: 모캡 · LiDAR 같은 고가 · 고중량 센서를 쓰지 않는다. 그것이 연구의 질문이다.
2. **한 부품이 한 가지 값을 책임**: 위치는 UWB, 속도는 광류, 장애물은 ToF, 이웃은 BLE.
3. **막힐 곳에 대안**: UWB ↔ ZED, 단일 빔 ↔ 멀티존, 동글 중계 ↔ 광고.
4. **못 찾은 선례는 시험으로**: "선례 없음"을 숨기지 않고 벤치 과제(Task 1 ~ 5)로 만들었다.

# 결과를 내는 방법

슬라이드 10의 근거다. "무엇을, 어떤 순서로, 어떤 기준으로 측정해서 결론을 내는가"를 정리한다. 현재 확보된 결과와 아직 없는 결과를 구분한다.

## 1. 보여 줄 결론 세 가지

| # | 결론 | 필요한 증거 | 현재 |
| --- | --- | --- | --- |
| 1 | 6대가 랜덤 목표점으로 무충돌 도달한다 | 충돌 0, 성공률, 최소 이격 거리 | 증거 없음 (실기체 시험 전) |
| 2 | 센서는 UWB · ToF · BLE만으로 충분하다 | UWB 위치 RMSE ≤ 0.15 m, BLE 요구치 충족 | BLE 충족(실측), UWB 거리는 LOS 양호 · 위치 미검증 |
| 3 | 통신량 · 연산량을 줄여도 안전은 유지된다 | E1 ~ E6의 통신량 · 계산 시간 대비 안전 지표 | 시뮬 예시(통신 98% 감소)만 있음 |

## 2. 단계별 진행과 진입 조건

| 단계 | 목표 | 주요 확인 | 다음 단계 진입 조건 [제안] |
| --- | --- | --- | --- |
| 1. 시뮬 | UWB · ToF 모델 추가, 알고리즘 비교 | 거리 노이즈 · NLOS 모델, 갱신율 영향, 주기 방송 vs 이벤트 트리거 | 시뮬 테스트 통과 (합격 기준 미정) |
| 2. 벤치 | 부품 책상 시험 | Task 1 ~ 5: UWB 위치, N6 QP 시간, BLE 엔드투엔드, ToF 5개 | 실측값을 시뮬 모델에 반영 |
| 3. 1대 | 실기 1대 비행 | EKF 융합, 속도 추종 τ, ToF 회피, 컴패니언 두절 시 FC 동작 | 호버 안정성, failsafe 동작 확인 |
| 4. 2대 | 피어 거리 · 링크 · 시계 동기 | 1 / 3 / 5 m 피어 거리 오차, 패킷 지연, 동기 오차, CBF 쌍 시험 | 2대 충돌 회피 확인 |
| 5. 6대 | 편대와 비교 실험 | 편대 제어, 채널 부하, E1 ~ E6 | 비교 실험 데이터 확보 |

현재 위치: 1단계(시뮬 기반 구축) 완료, 2단계(벤치) 진행 중.

## 3. 실험별 방법 (E1 ~ E6)

| 실험 | 독립 변수 | 고정 | 기록 | 기대 결과 |
| --- | --- | --- | --- | --- |
| E1 | 통신 방식 (20 Hz 방송 / 이벤트 트리거 / 중앙 우선순위) | 알고리즘 CBF-QP, 6대, 같은 목표 시퀀스 | 통신량, 최소 이격, 성공률 | 이벤트 트리거가 통신량을 크게 줄이면서 안전 유지 |
| E2 | 이벤트 임계값 δ | E1 이벤트 트리거 | 통신량 대 안전 손실 곡선 | δ 증가 → 통신량 감소, `D_eff` 증가 |
| E3 | 통신 지연 (BLE 연결 간격, 인위 지연) | | 최소 이격, 교착 비율 | 지연 증가 → `D_eff` 증가 → 교착 위험 증가 |
| E4 | 센서 구성 (ToF 유무 · 개수) | | 정지 장애물 회피 성공률 | ToF가 정지 장애물 회피에 기여 |
| E5 | 기체 수 (시뮬 6 → 20 → 50 → 100) | | 1주기 계산 시간(평균 · p99) 곡선 | 이웃 수에 비례. 이웃 선별 효과 |
| E6 | 회피 방식 (CBF / APF / ORCA / MPC) | | 최소 이격, 도달 시간, 계산 시간 | 지연 조건에서 CBF 우위 재확인 |

한 번에 한 요인만 바꾼다. 랜덤 목표 100회 반복으로 충돌 · 교착 통계를 낸다. 시뮬은 지연 τ · 위치 오차 · 통신 손실을 하나씩 추가해 "어떤 알고리즘이 어디서 깨지는지" 지도를 만든다. 기체 실험이 통과하면 "시뮬은 이랬는데 실제는 이랬다"를 비교한다.

## 4. 합격 기준

| 항목 | 기준 | 출처 | 상태 |
| --- | --- | --- | --- |
| UWB 거리 RMSE | ≤ 0.10 m | 9주차 | LOS 평균 오차 2 cm 안팎(Task 1). RMSE 산출 전 |
| UWB 위치 RMSE | ≤ 0.15 m | 9주차 | 검증 전 |
| 충돌 | 0.3 m 미만 접근을 충돌로 계수 | 8차 회의 | D_base 0.40 m와 정합 필요 |
| 성공 | 6대 랜덤 목표점 무충돌 도달 | 지도교수 | 시험 전 |
| BLE | 50 Hz × 64 B 무손실 | Task 4 | 충족 (한 홉) |
| 실시간성 | CBF-QP 1주기가 제어 주기 안에 끝남 (p99 기준) | | 미측정 |

## 5. 결과 정리 형식

| 산출물 | 내용 |
| --- | --- |
| 그래프 | BLE 처리량 · RTT · 거리별, UWB 오차(LOS / 가림), 통신량 대 안전 곡선, 계산 시간 vs 이웃 수 |
| 표 | E1 ~ E6 지표, 알고리즘 비교, 지연 예산(실측 교체본) |
| 영상 | 6대 비행, 회피 장면 |
| 로그 | 송수신 타임스탬프 포함 SD 로그 + 동글 텔레메트리 |
| 요약 문장 | "통신량을 X% 줄이고도 최소 이격 Y m를 유지했다" 형태 (X, Y는 실험 후) |

## 6. 실패했을 때의 이야기

| 상황 | 대응 | 발표에서 말할 것 |
| --- | --- | --- |
| UWB가 통과 기준 미달 | 고정 ZED 2i로 전환(8 m × 8 m) | 대안을 미리 설계한 것, 기준 미달 원인(가림) 분석 |
| 6대 비행 불가 (부품 부족, 탑재 중량) | 1 ~ 2대 실기 + 시뮬 6대 이상 | 시뮬과 실기체의 차이를 정량 비교 |
| D_eff 과대로 교착 | `v_max` 하향, 우선순위, 목표 재배정 | 안전과 진척의 트레이드오프를 결과로 제시 |
| 이벤트 트리거 절감 미미 | 급회피에서의 한계로 보고 | 한계도 결과다 |
| 비행 중 최소 거리 참값이 없음 | 시각 동기된 로그 + 지상 카메라 병행 검토 | 측정 방법 자체를 한계로 명시 |

## 7. 일정

종강 제출 12/14(예정). 남은 약 4주 동안 우선순위는 [진행 현황](../진행현황.md)의 "남은 일" 표를 따른다. 모든 단계를 끝내기 어려우면 3단계(1대 비행)까지 실측하고 나머지는 시뮬로 채운다. 이 결정은 팀 합의가 필요하다.

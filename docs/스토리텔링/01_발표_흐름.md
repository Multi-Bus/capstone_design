# 발표 흐름

최종 발표용 초안. 이야기의 뼈대는 **문제 → 왜 이 환경인가 → 왜 이 부품인가 → 왜 이 알고리즘인가 → 실측으로 확인한 것 → 결과를 어떻게 낼 것인가 → 남은 일**이다. 결정마다 근거 수치를 붙이고, 가정은 가정이라고 말한다.

발표 시간은 확정되지 않았다. 아래는 10분 기준이며 시간이 정해지면 슬라이드 수를 조정한다. 수치는 [설계](../설계/01_설계_결론.md)와 [실측 결과](../하드웨어/06_실측_결과.md) 기준이다.

## 장면별 대본 요점

### 1 ~ 2. 문제와 목표

- "물류센터의 높은 선반 작업은 사람이 하기 느리고 위험하다" → 3차원 이동 드론이 적합.
- 선행 연구 시뮬레이션: 넓은 영역 소요 시간 1대 257.05분 → 9대 54.28분. 다수 운용 효과는 있다.
- 그러나 대수가 늘면 간섭도 는다 → 편대 제어 + 충돌 회피 필요. 비행 시간이 길수록 필요한 기체가 줄어 경량화가 필요하다.
- 실제 물류센터는 규모 · 안전상 어려워 15 m × 15 m로 축소해 검증한다.

### 3 ~ 4. 접근과 시스템

- 새 알고리즘을 만들지 않는다. 검증된 CBF를 **안전 필터**로 쓰고, 편대 제어가 낸 속도를 최소한으로 고친다.
- 비싼 센서(모캡) 대신 UWB · ToF · BLE만 쓴다. 가볍게 만드는 것이 연구 질문이다.
- 구조도 한 장으로 센서 → 전처리 → 제어 → FC 흐름을 보여 준다.

### 5. 좌표계 결정 (이야기의 전환점)

- 6대가 같은 좌표계를 써야 `p_j - p_i`가 의미가 있다.
- 천장 360° 카메라는 시야각과 정확도 한계로 폐기. UWB 앵커 3개로 월드 프레임을 정의.
- "틀릴 수 있는 결정"이라 통과 기준과 대안(ZED 2i, 8 m × 8 m)을 함께 둔다.

### 6. 부품 선택

- 한 장에 센서 5종(UWB, ToF, 광류, 컴패니언, 무선)만. 표 하나: 고른 것 / 버린 것 / 이유 한 줄.

### 7 ~ 8. 실측

- "가정이 아니라 측정했다" 슬라이드. UWB는 좋은 소식(LOS)과 나쁜 소식(가림)을 같이 보여 준다.
- BLE는 요구치 충족, 그러나 연결 간격이 지연을 정한다는 것을 그래프로. 20 m 1회 실패도 숨기지 않는다.

### 9. 안전 여유

- 알고리즘이 아니라 **불확실성 하에서 안전거리를 얼마나 잡아야 하는가**가 실제 안전을 좌우한다.
- 시뮬: ORCA는 τ ≥ 0.5 s에서 침범, 여유를 둔 CBF는 τ = 1.0 s에서도 버텼다.
- 여유가 크면 교착 위험도 같이 커지는 트레이드오프.

### 10 ~ 11. 결과 계획과 현황

- E1 ~ E6을 한 장에, 지표를 세 묶음(안전 · 정확도 · 경량화)으로.
- 가장 큰 미지수는 속도 추종 지연 τ. 정직하게 "아직 모른다"고 말한다.

## 예상 질문

| 질문 | 답 |
| --- | --- |
| 왜 카메라를 버렸나 | 천장 360° 카메라는 시야각과 정확도 한계. 센서를 늘리면 무게와 전력이 는다 |
| UWB가 정확하지 않으면 | LOS 오차는 작고 가림이 문제. 이상치 제거와 앵커 증설을 검토. 통과 기준을 못 넘으면 ZED 2i로 전환 |
| 왜 BLE인가 | 실측에서 요구치(64 B × 50 Hz)를 손실 0으로 처리. Wi-Fi 대비 MCU 부담이 작다는 점은 비교 실험 전이라 단정하지 않음 |
| 드론끼리는 어떻게 통신하나 | 아직 한 홉(드론 ↔ 동글)만 측정. 동글 중계 2홉 / 광고 / UWB 페이로드 중 선택 예정 |
| 안전을 어떻게 보장하나 | CBF-QP가 명령을 최소 보정. 이웃 · 내 위치 오차 상한을 안전거리에 더함. 해가 없으면 감속 · 정지 |
| 왜 새 알고리즘이 아닌가 | 지도교수 방침: 실기체 제작과 시스템 완성도 우선. 통상 알고리즘(CBF, APF) 사용 가능 |
| AI는 안 쓰나 | 허용이지 필수가 아님. 쓴다면 `v_nom`을 학습 모델이 만들고 안전은 고전 CBF가 보장하는 구조 |
| 경량화를 어떻게 증명하나 | E1 ~ E6에서 통신량, 계산 시간, 메모리, 전력을 같은 방식으로 기록 |
| 가장 큰 위험 | 속도 추종 지연 τ (실측 없음). 이 값이 안전 여유를 정함 |
| 6대 실제 비행은 | 부품은 구매 완료. 모터 4개와 프롭 1세트 부족. 비행 시험은 τ 측정부터 |
| 시뮬과 실기체 중 무엇으로 평가하나 | 미결정. 시뮬은 확장성(6 → 100대), 실기체는 6대 무충돌 도달 |

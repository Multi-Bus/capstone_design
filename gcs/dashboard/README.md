# dashboard — 편대 리모트 대시보드 (가상 모드)

발표용 화면이다. 파란 그리드 무대 위에 쿼드콥터 6대가 있고, 버튼으로 시작, 중지, 편대 변경, 복귀를 명령하면 드론이 그대로 움직인다. 첫 버전은 가상 모드만 있다. 드론은 `swarm/`의 consensus 편대 제어와 CBF-QP 충돌 회피로 움직인다. 실기체 모드는 설계 문서의 "다음 단계" 조건(호버링 안정, 공통 좌표계, BLE 다중 연결)이 갖춰지면 만든다.

## 설치

```powershell
pip install -r gcs/dashboard/requirements.txt
```

## 실행

레포 루트에서 실행한다. 서버가 뜨면 브라우저가 `http://127.0.0.1:8000/`을 연다. 인터넷이 없어도 된다.

```powershell
python -m gcs.dashboard
```

## 테스트

```powershell
python -m pytest -q tests/test_dashboard.py
```

## 버튼

| 버튼 | 동작 |
| --- | --- |
| 시작 (S) | 지상의 드론이 이륙해 1 m 높이에 머문다 |
| 중지 (X) | 모든 드론이 그 자리에 착륙한다 |
| 일렬, 삼각, 원 | 떠 있으면 새 형태로 이동한다. 들어갈 공간이 없으면 거부한다. 지상이면 형태를 기억했다가 시작할 때 그 형태로 선다 |
| 복귀 (H) | A* 경로로 시작 위치 위로 돌아간다. 착륙은 중지로 한다 |
| 목표 지정 (G) | 켠 뒤 바닥을 클릭하면 편대가 A* 경로로 그 지점까지 간다. 편대가 들어갈 수 없는 곳(벽 가까이, 기둥 위)이면 가장 가까운 들어가는 곳으로 옮긴다. 떠 있을 때만 된다 |
| 장애물 배치 (O) | 켠 뒤 바닥을 클릭하면 기둥(반경 0.5 m)을 놓는다. 이동 중이면 경로를 다시 계획한다 |
| 장애물 지우기 (C) | 클릭으로 놓은 기둥을 지운다. 고정 기둥 3개는 남는다 |

단축키: 1, 2, 3 편대, S 시작, X 중지, H 복귀, Esc 도구 끄기.

마우스로 화면을 돌리고 확대할 수 있다. 서버가 꺼지면 화면에 "서버 연결 끊김"이 뜨고, 다시 켜면 1초 안에 다시 연결된다.

## 구조

| 파일 | 내용 |
| --- | --- |
| `server/formations.py` | 편대 자리 좌표(일렬, 삼각, 원), 시작 위치, 총거리 최소 자리 배정 |
| `server/sim.py` | 한 단계씩 도는 가상 시뮬 `SimSwarm`. 15 m 방, 기둥, A* 경로 추종 |
| `server/app.py` | FastAPI 서버. 시뮬을 실시간으로 돌리고 `/ws`로 상태를 보내고 명령을 받는다 |
| `web/` | three.js 화면. `vendor/`에 three.js 0.170.0(MIT), Pretendard(OFL), Phosphor 아이콘 경로(MIT)를 넣어 두었다 |
